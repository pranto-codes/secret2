# Birthday Secret Surprise ♡

Two-page Vite + React birthday experience.

Run:
```bash
npm install
npm run dev
```

Default secret password: `20102026`

Edit `src/data/content.js` to change the name, password, letter, memories, reasons and timeline.

Put photos in `public/photos/` as:
- memory-1.jpg
- memory-2.jpg
- memory-3.jpg

Put your song in `public/music/our-song.mp3`.

Build:
```bash
npm run build
```
